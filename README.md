# Pokémon Quiz

## Purpose
Tests Pokémon knowledge by quizzing them with flashcards.

## Requirements
- R1: The quiz shows a Pokémon name and asks for its type; the answer is checked ignoring upper/lower case and extra spaces.
- R2: After the last card, the program shows the score as correct/total and a percentage.
- R3: Blank or whitespace-only input is rejected and the same card is asked again; it never counts as a wrong answer or changes the score.

## Setup and use
- Prerequisites: Python 3.10+, no extra dependencies
- Setup: `git clone https://github.com/JayPS16/5.1_Sorawich_Pimsen_PokemonQuiz.git` then `cd 5.1_Sorawich_Pimsen_PokemonQuiz`
- Run: `python main.py` (type the type and press Enter, e.g. `electric`)
- Run tests: `python -m unittest -v`
